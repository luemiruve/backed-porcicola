# 🐷 Sistema Porcícola

Sistema backend para gestión de granja porcina.

## 🚀 Tecnologías
- Java (Spring Boot)
- PostgreSQL
- JPA / Hibernate

## 📦 Funcionalidades
- Gestión de animales
- Control reproductivo (ciclos, montas, camadas)
- Inventario
- Sanidad
- Notificaciones automáticas

## 🧠 Arquitectura
- REST API
- Patrón MVC
- DTO + Mapper

## 🔧 Base de datos
Incluye triggers para:
- Fecha de parto automática
- Alertas
- Control de inventario

## 📱 Futuro
- App Android (Kotlin)
- App iOS (Swift)
